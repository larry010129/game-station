Perk node icons

One icon per kind of effect, reused on every node with that effect, so 500 nodes need only 24 icons. The node's frame says what type it is (small, notable, keystone, bridge), and its colour says which region it belongs to. All drawn as simple line icons in one stroke weight, with no gold.

1. Node frames (type)

The same icon sits inside a different frame for each node type. Shown with the coin icon in the Credits colour.

2. Icon set (effect)

24 icons. Each one covers a family of stats, listed under it. Every small node uses its region's main icon; notables and keystones pick the icon of their stat.

3. How it reads per region

Small, notable and keystone side by side, in each region's colour. Taken nodes fill in.
