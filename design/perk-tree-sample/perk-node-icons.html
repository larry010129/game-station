Perk node icons

One icon per kind of effect, reused on every node with that effect, so 500 nodes need only 25 icons. The node's frame says what type it is (small, notable, keystone, bridge), and its colour says which region it belongs to. All drawn as shaded icons in three tones of the region colour, lit from the top left like the currency icons, with no gold.

1. Node frames (type)

The same icon sits inside a different frame for each node type. Shown with the coin icon in the Credits colour.

2. Icon set (effect)

38 effect icons and the keystone mark (13 added on 2026-11-18, in their class colours). Each one covers a family of stats, listed under it, and is shown here in its home region's colour. Every small node uses its region's main icon; notables and keystones pick the icon of their stat.

3. How it reads per region

Small, notable and keystone side by side, in each region's colour. The three bars under each set are that region's tones: lit, turned away, recessed.

4. States

A locked node drops to grey. A taken node fills with the region colour and the icon flips to dark ink, keeping its three tones.

5. At tree size

Every icon inside nodes of the size the tree sample uses: small nodes 30px across, notables 54px, keystones 80px at 100% zoom. The tree opens fitted to the window, at about a quarter of that, where small-node icons are far too small to read, so the tree brings icons in as you zoom closer: keystones from 30%, notables from 40%, small nodes from 70%.
