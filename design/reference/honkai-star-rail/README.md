# Honkai: Star Rail UI reference screenshots

Downloaded 2026-11-18 from https://interfaceingame.com/games/honkai-star-rail/ (all three listing pages): 62 screenshots at
1920 x 1080, plus the game's banner (1920 x 300) and cover (570 x 760). 64 files, about 31 MB.

These are the game's own screenshots, kept here only to look at while designing. The rule in `UI REFERENCE PLAN.md`
holds: take the layout pattern only; no names, art, icons, palette or wording go into the app. Consider keeping this
folder out of git.

## The two Travel Log screens (how daily login works)

- `honkai-star-rail-travel-log.png`: the **Daily Check-In** event. Left rail of events, kicker chip, big title, countdown,
  six day boxes in two rows and a tall Day 7. The app's Check-in page follows this one.
- `honkai-star-rail-travel-log-2.png`: another event in the **same** Travel Log rail, a level-milestone track ("reach level
  5 / 15 / 25 / 35, claim"), marked Permanent. It shows the rail is a hub of several login and progress events, not
  one screen.
