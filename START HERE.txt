DESKTOP APP
  Build:    in app, run  npm run prepare:sidecar  then  npm run tauri build -- --bundles nsis
  Install:  app\src-tauri\target\release\bundle\nsis\Command Station_<version>_x64-setup.exe
            (the installer takes its service folder from the current source, so it is always up to date)
  NOTE:     CommandStation-v0.2\ is an OLD hand-assembled copy with an outdated service folder
            (it lacks newer modules). Do not rely on it; rebuild with the steps above.
  Unsigned, so SmartScreen may warn: More info, Run anyway.
  Building it needs Smart App Control off (it blocks the build scripts).

COMMAND CMS (content publishing) - now its own repo and a website
  Website:  https://command-station-cms.yuzi010129.workers.dev  (sign in with Cloudflare Access)
  Code:     ..\command-station-cms  (repo larry010129/command-station-cms)
  Releases: https://command-station-releases.yuzi010129.workers.dev/releases  (what the app downloads)
  Local copy (optional): in command-station-cms run  npm run dev  ->  http://localhost:1430
  The app reads the Cloudflare releases; set VITE_RELEASES_BASE to use the local CMS instead.
  Signing keys are not in git: data\keys\*.pem on the CMS PC, and the SIGNING_KEY secret on the Worker.

Browser version (backup): open a terminal in app and run  npm run live
            Then open http://localhost:1420. Ctrl+C stops the service and the
            dashboard together, so nothing is left running in the background.

Nothing extra to install: GPU temperature, load, ping, battery and the
players-online map (Steam public data) all work on their own.

Your settings and the game-mode undo journal live in:
  %APPDATA%\CommandStation\   (service.log is there too)
